MoeMail

MoeMail is a temporary email service. It lets users create disposable email addresses, receive and view short-lived messages, choose automatic expiration periods, share selected mailboxes, and use an API for software testing and automation.

No login or account is required to view this page and understand the purpose of MoeMail.

What MoeMail does

Disposable email addresses

Create a temporary address without publishing a primary personal email address.

Receive temporary messages

Read messages delivered to temporary inboxes, including verification and testing messages.

Expiration and sharing

Choose mailbox expiration periods and share selected mailbox content through controlled links.

Developer API

Integrate temporary email workflows into software development, automated tests, and other developer tools.

Why MoeMail requests Google user data

Google Sign-In is optional and is used only to authenticate a MoeMail account. When a user chooses Google Sign-In, MoeMail receives basic profile information provided by Google: the user's name, email address, profile image, and provider account identifier.

MoeMail does not request access to Gmail, Google Drive, Google Contacts, Google Calendar, or other Google account content. Google user data is not sold and is not used for advertising.
